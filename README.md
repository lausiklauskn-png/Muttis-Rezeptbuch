# 📖 Muttis Rezeptbuch

Web-App zum Verwalten, Importieren und Organisieren von Rezepten.

---

## 🚀 Features

- 🌐 **Web-Import**
  - Rezepte direkt über URL laden
  - Bilder Import
  - zuverlässiger KI Scan mit Kamera
  - KI Scan von Einzeldateien und ganze Ordner
  - Rezepte manuell eintippen oder Einfügen
  - Datensicherung .json laden
- 📚 **Integriertes Handbuch in 8 Sprachen**
  - 9 Kapitel mit Navigation
  - Mehrsprachig (8 Sprachen)
  - PDF-Export
  - Ebook-EPUB3 Export
  - Html Blätterbuch möglich
  - Datensicherung .Json Backup
  - Backup-Tresor mehrere Sicherungen verwalten
  - Barrierefreiheit
  - Verschieden Themen Landhaus,Frühling,Nacht,Modern,Bunt
- 📂 **Rezept-Organisation**
  - Ordnerstruktur
  - Ordnerorganisation Drag and Drop Funktion
  - Menüplanung und Einkaufsliste mit Kadegorien und Sammelliste
  - KI Menüplaner für die ganze Woche oder mehrere Wochen
  - Portionsplaner
  - Rezeptübersetzer in 10 Sprachen
  - Rezepte Bilder manuell himnzufügen
  - Rezepte Teilen über Barcode
  - .json Dateien
  - PDF drucken
  - KI Nährwertberechnung 
  - Bewerte deinen Fortschritt/ Verbesserungsideen
- 📦 **Import / Export**
- 🤖 **KI-Funktionen**
- 📱 **PWA (Installierbar)**
  - Offline nutzbar
  - Zum Startbildschirm hinzufügen

## 🛠️ Installation (PWA)

1. Seite im Browser öffnen  
2. Menü (⋮) klicken  
3. **„Zum Startbildschirm hinzufügen“**

---

## 📂 Projektstruktur

- `index.html` → Hauptanwendung  
- `manifest.json` → PWA-Konfiguration  
- `sw.js` → Service Worker (Offline-Funktion)  
- `icons/` → App-Icons  
- `generate_icons.py` → Icon-Generator
