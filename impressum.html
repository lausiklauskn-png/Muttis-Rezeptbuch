2. Bereitstellung der App (Hosting)

Diese Anwendung wird über GitHub Pages bereitgestellt. Beim Aufruf der App werden technische Daten (z. B. IP-Adresse, Browserinformationen) an GitHub übertragen, um die Inhalte der App auszuliefern.

3. Lokale Datenverarbeitung

Alle vom Nutzer eingegebenen Inhalte (z. B. Rezepte) werden ausschließlich lokal im Browser gespeichert (z. B. LocalStorage oder IndexedDB). Es erfolgt keine Speicherung dieser Daten auf Servern des Betreibers.

4. Nutzung von KI-Diensten

Für die Funktion „KI-Scan" werden Inhalte (z. B. Bilder oder Texte) an externe KI-Dienste übermittelt, insbesondere an Anthropic (Claude).

Dabei gilt:

  • Die Übertragung erfolgt verschlüsselt
  • Die Daten werden ausschließlich zur Verarbeitung der Anfrage genutzt
  • Es erfolgt keine Speicherung durch den Betreiber

Hinweis: Die Verarbeitung erfolgt durch externe Anbieter. Es kann nicht ausgeschlossen werden, dass Daten im Rahmen der technischen Bereitstellung kurzfristig verarbeitet oder gespeichert werden.

5. API-Schlüssel

Der vom Nutzer eingegebene API-Schlüssel wird ausschließlich lokal im Browser gespeichert und nicht an den Betreiber der App übertragen.

6. Weitergabe durch den Nutzer
